# 第一周项目 01：命令行聊天程序

这个项目先使用本地练习后端，不需要 API 密钥，也不依赖第三方 Python 包。它用于练习第一周的程序结构：输入、消息历史、命令、JSON 文件和异常处理。

## 运行

在项目目录执行：

```powershell
python chat.py
```

可用命令：

- `/help`：显示命令
- `/clear`：清空当前内存中的对话
- `/save`：保存历史
- `/quit`：退出并自动保存

历史记录默认写入 `data/history.json`，也可以指定路径：

```powershell
python chat.py --history data/my-history.json
```
